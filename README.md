# Квиз

Веб-приложение для проведения квизов: htmx + Go + Postgres.
Страницы собираются на сервере, htmx подменяет отдельные фрагменты.

## Запуск

```bash
docker compose up --build
```

Приложение поднимется на <http://localhost:8080>, база — на порту 5433.
Схема применяется автоматически при старте.

Вход администратора — токен `change-me-admin-token-01`
(задаётся переменной `ADMIN_TOKEN` в `docker-compose.yml`, поменяйте его).

Разработка с приложением на хосте и базой в Docker:

```bash
make run
```

## Как устроено

Вход единый: и админ, и игрок вводят токен. Пароля нет.
Админ создаёт игроков — токен генерируется автоматически и виден в списке.

Админ собирает квиз: квиз → раунды → вопросы. Вопрос бывает двух видов:

- **выбор из вариантов** — баллы начисляются сразу при ответе;
- **свободный ввод** — ответ попадает в очередь на проверку, баллы
  начисляются после решения админа.

У каждого вопроса два числа: баллы за верный ответ и баллы за неверный
(второе может быть отрицательным). Для свободного ввода можно задать
подсказку — её видит только админ на странице проверки.

Игрок проходит квиз в своём темпе, по одному вопросу. Обратной связи по ходу
нет; в конце — экран результата и таблица рейтинга.

## Структура

    cmd/quiz            точка входа
    internal/config     чтение окружения
    internal/domain     структуры данных
    internal/storage    запросы к Postgres
    internal/auth       генерация токенов
    internal/quiz       подсчёт баллов
    internal/web        роутинг, обработчики, шаблоны и статика
    migrations          SQL-миграции

## Команды

    make up      собрать и запустить всё в Docker
    make run     база в Docker, приложение на хосте
    make test    тесты
    make lint    gofmt и go vet
    make down    остановить и удалить данные
